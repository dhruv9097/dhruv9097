### 🌉 [ShramSetu](https://github.com/dhruv9097/shram-setu)
**The bridge that moves with the worker.**

*Smart India Hackathon — PS1, Ministry of Labour & Employment.*
eShram records **31.89 crore** workers once, at enrolment, against a home address. Then
they migrate and the record stays behind. ShramSetu reframes tracking as **presence the
worker marks themselves** — because the attestation pays back the same day: portable
ration, proof of employment, a verifiable work history.

- 📴 **Offline-first** — check-ins queue in IndexedDB, flush on reconnect
- 🔒 **Privacy by design** — district-level storage + k-anonymity on every official view
- 📱 **Zero-literacy UX** — QR → one-tap geofence → missed-call IVR fallback

`Next.js 16` `React 19` `Prisma` `PostgreSQL` `Zod` `D3-geo` `Recharts`

### 🤖 [Social Media Automation Engine](https://github.com/dhruv9097/social-media-automation)
**A 7-phase multi-agent growth engine.**

Seven specialised Python agents run as one orchestrated pipeline: Spy (7-day competitor
scrape via Apify) → Auditor (gap analysis) → Image Analyst (Gemini Vision) → Trend Hijack (world-trend
scoring) → Architect (thread drafts) → Engagement (Golden Hour replies) → Image Generator.

- 🔁 **Dual-mode pipeline** — `--live` and a safe `mock` mode for free iteration
- 📊 **Quota-managed** LLM calls with persisted state and structured JSON reports
- 🖼️ Vision-model reading of competitor image posts

`Python` `Gemini Vision API` `Apify` `Pollinations.ai` `requests`

### 📈 [GitHub Trending Dashboard](https://github.com/dhruv9097/github-trending)
**Scrape → score → surface, end to end.**

A Python scraper parses GitHub's daily trending page, computes a custom **Hype Score**
(1.25× daily star growth), and exports a clean dataset that a Next.js 16 / React 19
frontend renders as a live, sortable leaderboard — with one-click clone.

- 🧹 Full pipeline: raw HTML → BeautifulSoup → Pandas → CSV → typed frontend
- ⚡ Server Actions trigger the Python sync and revalidate the view in place

`Python` `BeautifulSoup` `Pandas` `Next.js` `TypeScript` `Framer Motion`
